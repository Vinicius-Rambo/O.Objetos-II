## Orientação a Objetos II

**Componente** Curricular: Orientação a Objetos II  
**Semestre**: 3º  
**Carga** **horária**: 80h (67h relógio)  
**Professor**: Humberto Martins Beneduzzi

---
## Objetivo

Aprofundar o conhecimento no **paradigma de programação orientada a objetos**, explorando conceitos mais avançados e sua **implementação prática em uma linguagem de programação**.

A disciplina busca desenvolver a capacidade de:

- Estruturar sistemas utilizando boas práticas de orientação a objetos
- Aplicar conceitos avançados no desenvolvimento de software
- Integrar aplicações com **bancos de dados**
---
## Ementa

- Interfaces
- Classes abstratas    
- Membros estáticos
- Membros finais
- Pacotes
- Meta programação e reflexão
- Uso de coleções
- Mapeamento Objeto-Relacional (ORM)
- Acesso a banco de dados
- Tipos genéricos
- Tipos enumerados
